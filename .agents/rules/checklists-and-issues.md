# Atualização Imediata de Checklists e Issues

Sempre que estiver trabalhando com issues do GitHub ou qualquer checklist de tarefas/objetivos:

1. **Marcação Progressiva Imediata:**
   - Assim que um objetivo, entrega técnica, critério de aceitação ou sub-item for concluído e validado, marque a respectiva caixa (`- [x]`) **imediatamente**.
   - Não acumule atualizações de checklist para o final da tarefa ou apenas quando solicitado.

2. **Sincronização no GitHub:**
   - Em issues do GitHub, atualize o corpo da issue (`gh issue edit <NUM> --body ...` ou via arquivo temporário seguro) refletindo as etapas já superadas conforme o progresso avança.

3. **Visibilidade e Rastreabilidade:**
   - Informe explicitamente no chat quais itens acabaram de ser concluídos e marcados para manter o usuário ciente do avanço em tempo real.
